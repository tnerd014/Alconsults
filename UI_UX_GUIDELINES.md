# UI / UX Design Guidelines

## Core Principles
1. **Minimalist & Intentional**: Avoid unnecessary text, bloated empty-state prose, or decorative cards.
2. **Anti-AI Slop**:
   - No static pill capsules or candy badges for metadata.
   - No code-comment headers (`// 01 ARCHITECTURE`).
   - No decorative pulsing dots or artificial telemetry tickers.
   - Restrained, consistent visual hierarchy.
3. **Desktop Optimization**:
   - Persistent 240px sidebar with logical grouping: Workspace, Business, Management, System.
   - Multi-column tables with sortable headers, tabular numeric fonts (`font-mono tabular-nums`).
   - Split views for instant side-by-side editing.
4. **Android Mobile Optimization**:
   - Ergonomic 5-item bottom bar: Home, Clients, Projects, Finance, More.
   - Touch targets $\ge 44\text{px}$.
   - Bottom sheets for quick actions (Record Payment, Quick Note, Fast Status Change).
5. **Client Portal Optimization**:
   - Distraction-free, high-trust client interface.
   - Zero exposure of internal margins, notes, or contractor costs.
   - Direct action points: Approve Quotation, Download Receipt, Pay Invoice, Submit Change Request.
